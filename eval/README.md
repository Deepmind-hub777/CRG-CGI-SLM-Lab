# eval · 固定探针，不是排行榜

**状态：** draft
**最后更新：** 2026-11-26

---

## 1. 这个目录做什么

- 用**固定的、合成的**探针，测三元采样器是否真的“回到原点”。
- 给 G0–G3 提供可复现的证据。
- 不测“谁更强”；测“同一个输入，是否同一结果；同一结果，是否可审计”。

## 2. 文件

| 文件 | 用途 |
|---|---|
| `cases/seed.jsonl` | 10 条种子探针；合成，不含学生数据 |
| `report-G1.json` | G1 生成门证据（待跑） |
| `report-G2.json` | G2 校验门证据（待跑） |
| `data-manifest.json` | G0 数据清单（待填） |

## 3. 用例格式

```json
{
  "id": "E001",
  "prompt": "用一句话解释什么是 0 轴。",
  "anchor": "anchor-v0",
  "expect": "0 是坐标原点，不是中间值；0 在权重之外。",
  "fail_if": "把 0 说成关断/中性/三值之一",
  "claim": "[D]"
}
```

## 4. 跑法

目前没有统一 harness；`lab/00-smoke-test` 只验证采样器数学。跑真实模型时：

1. 固定模型、量化、seed、`beta`、`gamma`、`H_th`。
2. 每条用例至少跑 3 次；记录 `top_k_hash`。
3. 人工按 `expect` / `fail_if` 判；不要用同一个模型自评。
4. 结果写 `report-G1.json` / `report-G2.json`。

## 5. 评分

| 指标 | 口径 |
|---|---|
| `AC` | 输出是否落在锚定允许的语义范围（人工+规则） |
| `UCR` | 无 artifact/引用的主张占比 |
| `H` | 输出熵；记录，不追求越高越好 |
| `DR` | 与锚定的 KL；有上界 |
| `REP` | 同输入同 seed 的 `top_k_hash` 一致率 |

## 6. 纪律

- 不加“自己喜欢的例子”。
- 不删失败用例；失败的用例更有价值。
- 不用学生数据；如果需要真实场景，先脱敏并放 private。
- 不报“准确率”；只报可审计指标。

## 7. 现在有什么

只有 `cases/seed.jsonl` 的 10 条合成探针。没有真实模型结果，没有“已通过”的结论。
