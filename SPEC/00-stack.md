## 1. 三层，不是三层并列

```text
[0 轴] Milo / Ring0
   │  宪制意图、最终裁决
   ▼
[CRG] Constitutional Runtime Governance
   │  不变宪制边界（静态焊死）
   │  + 运行时正则化（动态纠偏）
   ▼
[CGI] Controlled General Intelligence
   │  数学母题：e^{iπ}+1=0
   │  85% e 算力 + i 高维旋转 + π 十二时序（7.83 Hz 为既有口径）+ 外置 +1 碳基君核 = 0
   ▼
[SLM] 本仓库的工程层
   │  解码 / 锚定 / 后训练 / 端侧运行时 / 评测
   ▼
[Petros / Logikos] 端侧执行 / 云端审计
```

**道-数-术三层：**

| 层 | 名称 | 角色 | 本仓库是否重写 |
|---|---|---|---|
| 道统本体 | TYIRG | 三易归序自振；连山 -1、归藏 0、周易 +1；君臣佐使四维；15/85；七域同构 | 不重写 |
| 数学母题 | CGI | Controlled General Intelligence；欧拉恒等式锚 | 不重写 |
| 工程引擎 | CRG | Constitutional Runtime Governance；C/R/G；双层治理 | 只引用，不改定义 |
| 量化审计 | VRS³ | V 40 / R 30 / S 30；加权几何平均 | 只引用，不改权重 |
| 实体 | Petros / Logikos | 端侧 / 云端 | 只对接，不在此仓库实现 |

**冲突规则：** 若本仓库的工程口径与上层文档冲突，以上层为准；若上层未定义，开 RFC，不在代码里私自补定义。

## 2. 本仓库的 SLM 边界

### 2.1 在范围内

- 解码层：三元采样器、锚定检索、熵门控、独立校验。
- 后训练层：QLoRA / 双 adapter；0 外置；router 冻结；GGUF 导出。
- 端侧层：Termux + llama.cpp；手机基准；温控、内存、回滚。
- 评测层：固定探针、VRS³ 映射、G0–G3 门禁、失败记录。
- 协议层：SPEC、GOVERNANCE、GLOSSARY、PR 模板、RFC。

### 2.2 不在范围内

- 从零预训练；新 tokenizer；大规模 RLHF。
- 多模态；语音；产品 UI；商业运营。
- NAC 学生数据、家长报告、学校合同、真实教师轨迹。
- 任何模型权重、API key、受限语料。

### 2.3 四条硬边界

1. **0 不训练。** 0 是冻结参照；训练只能让模型“回到 0”，不能“成为 0”。
2. **-1 独立。** 校验器不能是生成器的同一个 adapter；不能自己批自己。
3. **数据分库。** 教务数据与研究数据物理分开；public 仓库只放研究层。
4. **公开先减法。** 先列不能公开的，再公开；公开不可逆。

## 3. 主张分层

每条判断必须带一个标签：

| 标签 | 定义 | 例子 | 允许的位置 |
|---|---|---|---|
| `[A]` | 神学叙事 / 本体论表达 | “陀螺的轴心是基督论锚点” | 序言、背景；不进 SPEC |
| `[B]` | 推演 / 类比 / 假设 | “三元算子可类比为进动抑制” | 设计讨论、RFC |
| `[C]` | 实证 / 待证 | “在 Qwen3-4B 上，β=0.6 使锚定一致率从 0.41 升到 0.63” | eval、lab、FAIL |
| `[D]` | 工程规则 / 可执行约束 | “0 的哈希必须写入每条 trace” | SPEC、代码、门禁 |

**规则：**

- 没有标签的主张，不进入 SPEC。
- 没有 artifact 的 `[C]`，不算结论，只算观察。
- `[B]` 不能写成 `[D]`；`[A]` 不能写成 `[C]`。
- 对外话术：只说“同一输入同一结果、可复现、可审计”；不说“准确”“零幻觉”。

## 4. 术语不重写

TYIRG、CGI、CRG、VRS³ 是 Ring0 既有术语。本仓库只做三件事：

1. 登记它们在 SLM 层的**操作化定义**。
2. 把模糊词变成**可测字段**（见 `03-metrics-and-gates.md`）。
3. 把比喻变成**参数或门禁**，并标注“不是物理常数”。

如果发现术语冲突：

- 开 `proposals/rfc/`；
- 由 Milo 裁定；
- 代码 PR 不能顺手改定义。
