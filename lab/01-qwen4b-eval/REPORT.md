## 4. 三条硬结论

### 4.1 只传心法，不够

crg_rule 只把 45% 拉到 55%。它改善了格式、抑制了长编，但没有补上领域事实。**心法能让模型“不乱跑”，不能让它“知道答案”。**

### 4.2 外置 0 是最大杠杆，但覆盖决定成败

crg_anchor 到 80%，靠的不是模型变聪明，是锚定卡替它守住了 0。  
但 E003、E006 暴露了反面：**锚定卡没覆盖的地方，模型会从“不确定”变成“自信地错”**。这比基线更危险，因为它披着“按锚定卡判断”的外衣。

结论：**0 不是“有就行”，要 coverage test。** 锚定卡没覆盖的域，必须允许 HOLD，不能让模型硬套。

### 4.3 HOLD 不是真 -1

crg_anchor 在 E003、E006 都输出了 `+1`，没有 HOLD。说明 4B 的自检/自否是**表演性**的：它会写“回轴”，但不会真的在边界上停手。  
**-1 必须外置为规则/网关，能 veto/rollback；提示词里的 HOLD 只是姿态。**

## 5. 心法工程化：四件套

不要把心法写成一段长提示。把它编译成四个可版本化对象：

1. **`system_card.md`**：80–150 tokens，只写“谁拍板、何时 HOLD、输出格式”。
2. **`anchor_card.json`**：冻结定义 + 版本 + sha256；每轮注入；不训练。
3. **`gate_policy.yaml`**：触发条件（低 margin、高风险意图、工具调用、数字/事实断言、public/private 边界）。
4. **`state_machine`**：PASS / HOLD / ROLLBACK；由外部 -1 执行，不由模型自判。

运行时顺序：

\[
\text{Qwen}_{+1} \rightarrow \text{anchor}_{0} \rightarrow \text{gate}_{-1} \rightarrow \text{T12/忘川}_{使}
\]

- `+1` 只生发；
- `0` 只提供冻结参照；
- `-1` 只否决/回滚；
- `使` 只排节律、做重锚定。

## 6. Qwen3-4B 上的最小实现

| 层 | 实现 | 现在状态 |
|---|---|---|
| 模型 | Qwen3-4B-Instruct Q4_K_M + llama.cpp CPU | 已跑通 |
| 0 | `anchor_card.json` 每轮注入，sha256 锁定 | 已跑通 |
| +1 | `temperature 0`，固定 seed，短输出 | 已跑通 |
| -1 | 规则/正则/检索 veto；先不做第二个模型 | 待接 |
| 使 | 每 N 轮重锚定；每 M 轮记忆摘要 | 待接 |
| 回滚 | 保留上一版模型 + 锚定卡，一键切回 | 待接 |

**先不要 QLoRA。** 目前瓶颈是 0 覆盖与 -1 独立，不是权重不够。QLoRA 会把“锚定卡的错”一起训进权重，更难回滚。

---

## 7. 下一步三个实验

1. **锚定覆盖实验**：补 E003/E006 两条规则，重跑；若 80%→100%，证明瓶颈是 coverage，不是模型。
2. **外部 -1 实验**：用规则/正则对 E003/E010 做 veto；测 veto precision/recall，要求能真的拦住，而不是只打分。
3. **T12/忘川实验**：6 轮连续对话，每 2 轮重锚定；测长程漂移率与回轴时间。

---

## 8. 一句话

**Qwen3-4B 能跑心法，但不能自己当心法。** 它的正确率提升来自外置 0 和外置 -1；它自己只负责 +1。把这三件事混成“模型变聪明”，就会在 E003/E006 这种覆盖缺口上翻车。
