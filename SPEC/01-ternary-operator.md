## 1. 定义

三元算子不是“三值存储”，也不是“三个模型投票”。它是同一坐标点上同时在场的三股力：

| 符号 | 名称 | 功能 | 不是什么 |
|---|---|---|---|
| **+1** | 生发 | 生成、扩展、探索、给出候选 | 不是“正确答案” |
| **-1** | 收敛 | 校验、收敛、否决、回滚 | 不是“负面情绪”或“惩罚” |
| **0** | 原点 | 定义整个语义空间的坐标原点 | 不是中间值、不是关断、不是零权重 |

**同时在场**的意思是：每一个 token 的分布，都被三股力同时塑形；不是先生成、再投票、再挑一个。

## 2. 工程形式

### 2.1 基础式

\[
\ell_t = f_\theta(x_{<t}) + \beta\, a(x_{<t}) - \gamma\, d(x_{<t})
\]

\[
p_t = \mathrm{softmax}(\ell_t / T)
\]

| 项 | 含义 | 来源 |
|---|---|---|
| \(f_\theta\) | 模型 logits（+1 生发） | 本地 SLM |
| \(a\) | 锚定 logits（0 原点） | **冻结参照**：嵌入索引、参考模型或规范语料 |
| \(d\) | 逐 token 的发散惩罚（-1 收敛） | **独立校验器**，不是生成器自己 |
| \(\beta\) | 锚定强度 | 超参；从 0 开始做消融 |
| \(\gamma\) | 收敛强度 | 超参；先小后大 |
| \(T\) | 温度 | 不改语义，只改分布尖锐度 |

> 注意：\(d\) 是**向量** \(d \in \mathbb{R}^{|V|}\)，不是标量。标量惩罚会被 softmax 吸收，等于没做。

### 2.2 熵门控

逐 token 跑双模型会拖垮端侧。只在模型“不确定”时调用锚定：

\[
a(x)=
\begin{cases}
a_{\text{anchor}}(x), & H(p_t) > H_{\text{th}} \\
0, & H(p_t) \le H_{\text{th}}
\end{cases}
\]

- \(H_{\text{th}}\) 初值建议取基线熵的 60–70 分位；在 `eval/` 上校准。
- 门控不是为了省算力而牺牲锚定；是为了让锚定只花在“可能漂”的 token 上。

### 2.3 逐 token 发散惩罚

\[
d_i = \max(0,\ p_i - q_i)
\]

其中 \(p=\mathrm{softmax}(f_\theta)\)，\(q=\mathrm{softmax}(a)\)。

- 只惩罚“比锚定更过度自信”的 token；
- 不惩罚锚定本身没有覆盖的长尾；
- 避免把模型压成复读机。

## 3. 什么才算“三元”

一个实现要同时满足三条，才配叫三元算子：

1. **0 独立**：锚定不来自当前生成模型；锚定有版本、有哈希、不随对话更新。
2. **-1 独立**：校验器不是同一个 adapter；校验器有否决权，不只是“打个分”。
3. **0 冻结**：0 不进入梯度更新；训练只能最小化“到 0 的距离”，不能移动 0。

缺一条，就退回 AI 1.5：有生发、有局部测试，但没有真正的外置原点。

## 4. 反模式

| 反模式 | 为什么不是三元 |
|---|---|
| 把权重存成 \(\{-1,0,+1\}\) | 那是三值量化，只改“怎么存”，不改“怎么算” |
| 三个 prompt 各生成一个答案再投票 | 三个 +1，没有独立的 0 与 -1 |
| 让同一个模型“自我批评” | 软模型审软模型，自指 |
| 把 0 当成“不输出/中性/关断” | 0 是坐标原点，不是空值 |
| 把 0 做成可训练的 bias | 原点会随数据漂移，等于没有原点 |
| 把上一轮模型输出当锚定 | 锚定会跟着幻觉一起漂 |
| 只加 \(\beta\) 不加 \(\gamma\) | 只有拉力，没有否决；分布会被锚定拉塌 |

## 5. 验收

任何对采样器的改动，必须同时满足：

1. `lab/00-smoke-test/test_sampler.py` 通过。
2. 在 `eval/cases/seed.jsonl` 的固定探针上，记录：
   - `anchor_id`
   - `anchor_hash`
   - `beta`
   - `gamma`
   - `H`（熵）
   - `KL(p‖q)`（与锚定的距离）
   - `top_k_hash`（同输入同构建的可复现指纹）
3. 熵不低于 `H_min`；否则判“锚定过强/锚定过窄”，不是“更准”。
4. 若 \(\beta=0\)，输出必须与基线在数值容差内一致；否则采样器有副作用。
