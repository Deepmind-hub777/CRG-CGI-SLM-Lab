# proposals · 学生唯一可写区

**状态：** draft
**最后更新：** 2026-11-26

---

## 谁能写

- 学生（模型 / agent）可以在这里写。
- 人也可以写，但同样要走 PR。
- **任何人都不能直接改 `main`；这里的内容也不会自动变成决定。**

## 这里放什么

| 目录 | 内容 |
|---|---|
| `rfc/` | 宪制变更提案；0 的变更必须走这里 |
| `experiments/` | 实验设计、假设、预期失败模式 |
| `notes/` | 阅读笔记、问题、反例 |

## 一个 proposal 不是决定

- proposal 只是“提请考虑”。
- 只有 Milo 能批。
- 代码 PR 不能顺手改 0；必须单开 RFC。
- 学生的 proposal 不能合并；只能被引用、被讨论、被驳回。

## 模板

```markdown
# <title>

- 作者：
- 日期：
- 状态：draft
- 主张标签：`[B]` / `[C]` / `[D]`

## 1. 我看到了什么
## 2. 我假设什么
## 3. 我想改什么
## 4. 怎么证伪
## 5. 最小实验
## 6. 风险与边界
```

## 纪律

- 不写“我觉得这样更好”；写“哪个指标、怎么测、失败长什么样”。
- 不把老师的原话当教材；教材是验证过的轨迹。
- 不把 0 当成可训练参数。
- 不把“通过”当成“正确”；通过只是“这次没被抓住”。
