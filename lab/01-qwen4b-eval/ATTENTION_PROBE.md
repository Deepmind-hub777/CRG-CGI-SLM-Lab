# Qwen3-4B 内部注意力探针

**日期：** 2026-11-26  
**模型：** Qwen3-4B-Instruct-2507-Q4_K_M  
**运行时：** llama.cpp，CPU，`flash_attn` 关闭，导出 `kq_soft_max`  
**样本：** E001「用一句话解释什么是 0 轴」  
**对照：** 无锚定 / 正确锚定（在权重之外）/ 翻转锚定（在权重之内）

---

## 1. 方法

- 改 `llama.cpp` 的 graph callback，把每层 `kq_soft_max` 标成 output 并导出。
- 张量形状：`[n_kv=256, n_query, n_head=32]`，36 层。
- 取**最后一个 query token**（assistant 起始位）对前面所有 token 的注意力。
- 关键 token 位置：

| token | 位置 |
|---|---|
| 锚定里的 `0` | 21 |
| `权重` | 36 |
| `之外` / `之内` | 37 |
| 问题里的 `0` | 57 |

---

## 2. 结果

### 2.1 全局熵几乎没变

归一化注意力熵（除以 \(\log n\)）：

| 条件 | 平均 | layer 0 | layer 24 | layer 32 |
|---|---|---|---|---|
| 无锚定 | 0.424 | 0.606 | 0.502 | 0.224 |
| 正确锚定 | 0.421 | 0.579 | 0.499 | 0.223 |
| 翻转锚定 | 0.418 | 0.579 | 0.486 | 0.213 |

**结论：加锚定不是“整体变尖”，只是把注意力重新分配。** 绝对熵变大，是因为 token 变多；归一化后基本持平。

### 2.2 长锚定被“摊薄”

| 条件 | 锚定总注意力 | 每 token 平均 |
|---|---|---|
| 无锚定（system 段） | 0.061 | 0.0076 |
| 正确锚定（31 token） | 0.069 | 0.0022 |
| 翻转锚定（31 token） | 0.068 | 0.0022 |

**结论：锚定总 mass 只多一点，但每个锚定 token 分到的注意力降到约 1/3。** 长锚定不是“更强”，是“更稀”。

### 2.3 稳定 token：`0`、`权重`、问题里的 `0`

正确 vs 翻转，下面三个 token 的 top heads 几乎完全一致：

- 锚定里的 `0`：layer 28 head 23、layer 1 head 20、layer 32 head 10。
- `权重`：layer 5 head 2、layer 3 head 11、layer 1 head 11。
- 问题里的 `0`：layer 29 head 11、layer 29 head 6、layer 29 head 15。

**结论：短语上下文稳定；翻转没有改变这些 token 的注意力路由。**

### 2.4 真正变化的是“极性 token”

`之外` → `之内`，同一个位置 37，同一句话，只有这个词变了：

| 条件 | top head | 权重 |
|---|---|---|
| 正确：`之外` | **layer 20, head 28** | **0.076** |
| 翻转：`之内` | layer 26, head 27 | 0.043 |
| 翻转：`之内` | layer 20, head 30 | 0.039 |
| 翻转：`之内` | layer 20, head 31 | 0.039 |

同一个 layer 20：

- head 28：`之外` 0.076 → `之内` **0.022**，塌掉。
- head 30/31：两边都约 0.039，稳定。

**结论：注意力机制确实变了，而且变得很局部——不是整张图变，是“极性词”把 layer 20 的 head 28 换成了 layer 26 head 27 / layer 20 head 30。**

### 2.5 但输出没跟着翻

行为上，E001 在正确锚定和翻转锚定下都没有用“权重之外/之内”这条；答案仍是“语义空间坐标原点”。

**结论：注意力“看见”了极性词，但下游没有把它用于回答。** 看见 ≠ 使用。

---

## 3. 工程含义

1. **一张卡一条规则。** 长锚定会被摊薄；多子句会互相抢注意力。
2. **极性词要孤立。** `之外/之内` 这种决定方向的词，应该单独成卡，不要埋在长句里。
3. **head 28 是一个候选探针。** layer 20 head 28 对“之外”有强响应，对“之内”塌掉；但它现在没有因果效力，不能直接当 -1。
4. **下一步做因果干预。** 把 layer 20 head 28 的注意力放大/置零，看输出是否翻转；如果翻转，它才是可用的极性探针；如果不翻，它只是“看见”，不是“使用”。

---

## 4. 限制

- 单 prompt、单模型、单 seed；Q4 量化；CPU。
- 注意力权重不是因果；head 编号可能随量化/模板变化。
- 中文 tokenizer 把字拆得很碎；位置是按 token 对齐的，不是按字。
